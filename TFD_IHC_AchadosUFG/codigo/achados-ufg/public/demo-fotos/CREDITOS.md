# Créditos das fotos de demonstração

As fotos desta pasta vêm do **Wikimedia Commons** e são usadas conforme suas licenças abertas (CC0, domínio público ou Creative Commons com atribuição).
Todas foram **redimensionadas** (lado maior ≤ 900 px) e convertidas para JPEG; quando indicado, também foram **recortadas**. Obras derivadas de fotos CC BY-SA ficam sob a mesma licença.

A imagem `carteirinha.png` é uma **ilustração fictícia** criada para o projeto (nome e matrícula inventados), usada para demonstrar o aviso de dados pessoais sem expor uma pessoa real.
